# 시티트리클럽 주니어

서울환경연합과 함께하는 **팀 나무늘보** 제작. 팀원: 김현진, 김나현, 박서연, 정경섭, 최미혜.

실제 시티트리클럽의 공개 화면·코드를 조사한 기능을 주니어의 돌봄 게임과 연결한 웹앱입니다. 조사 범위와 원본 서버에서 검증하지 않은 항목은 `docs/citytree-live-audit.md`, 캠페인 5페이지·19개 게시물 분석은 `docs/reference-analysis.md`에 기록했습니다. 원본의 인증키·사용자 사진·코드를 복사하지 않았습니다.

## 온라인 실행 · GitHub 자동 배포

로컬 서버 없이 GitHub Actions에서 검사·빌드하고 Cloudflare Workers/D1/R2로 배포합니다. [최초 계정 연결과 자동 배포 안내](docs/github-deployment.md)를 참고하세요. GitHub Pages 단독으로는 서버 API·DB·사진 저장이 동작하지 않습니다. 저장소의 비공개 설정을 바꿀 필요는 없습니다.

CI는 Node.js 24를 사용합니다. `.openai/hosting.json`의 `DB`/`BUCKET`은 논리 바인딩이며 기본 `wrangler.jsonc` UUID는 빌드 검사용입니다. 실제 배포 구성은 GitHub 변수로 생성하고 인증키는 GitHub Secrets에서만 읽습니다.

## 첫 돌봄

1. 서울숲 위치와 반경을 선택하고 가까운 10그루 중 무작위로 나무를 만납니다.
2. 내 나무에 이름을 선물합니다. 나무별 첫 작명은 10 XP입니다.
3. 물 10 XP, 거름 15 XP, 샘플 방문 20 XP를 얻습니다. 물뿌리개·물방울·축하 효과가 나타납니다.
4. 꼬물꼬물 돌봄, 가지 돌봄, 흙 돌봄 게임에서 표시된 5개 목표를 완료합니다. 종류별 하루 25 XP입니다.
5. 경험치 0/30/80/160/300에서 씨앗부터 울창한 나무까지 성장합니다. 다음 단계까지 남은 경험치가 표시됩니다.
6. 전체 돌봄 포인트 100부터 실물 이름표·메시지·고백·장식 이벤트에 응모할 수 있습니다.

경험치·성장·돌봄 횟수·애칭·꾸미기는 나무별이고, 돌봄 포인트와 일일 보상 제한은 계정 전체에 적용됩니다. 작명 보상은 나무별 최초 한 번입니다. 게임은 서버 발급 목표·세션·나무·3초~10분 완료 시간·재사용 여부를 검사합니다. 이는 기본 무결성 검사이며 봇·클라이언트 조작을 완전히 방지하는 인증은 아닙니다.

## 원본에서 이어받은 기능

- 실제 이동·확대 가능한 Leaflet/OpenStreetMap 지도, 위치·좌표·반경 검색, 거리순 상위 10개 무작위 배정
- 내 나무 최대 5그루, 활성 나무 선택·작별, 관심나무 등록·해제, 수종/이름 검색
- 수종→애칭→건강 체크 9항목+해당없음→둘레/덩치→사진/소감 다단계 관찰
- 공개·비공개 관찰, 다른 나무의 관찰, 내 기록 수정·삭제, 댓글·댓글 사진·좋아요·공유
- 사진 업로드·개별 삭제·접근 권한. 클라이언트에서 1200px 이내 JPEG 재인코딩, EXIF 제거, 자연/흑백/따뜻한 필터. 서버는 파일 서명·MIME·3MB 크기 검사
- 활동 이름·최대 3개 지역, 읽음/안읽음 알림, 현재 체험 계정과 관련 데이터 삭제
- 지도 오류·새 나무·사라진 나무 제보, 위치·사진·수종·건강·둘레·덩치 저장
- 낮/밤 모드(시스템 기본 + 수동 설정), 동작 줄이기 지원, 키보드 조작 게임

현재 목록은 최근 관찰 100개, 알림 100개까지 표시합니다. 실제 운영의 페이지네이션·검색 인덱스는 후속 확장 항목입니다.

## 실물 이벤트

100 누적 포인트 이상, 종류별 1회, 포인트 차감 없이 응모합니다. 시작일은 내일부터 90일 이내, 전시 기간은 1/3/7일 중 선택합니다. 종료일은 시작일 포함 계산하며 해당 날짜에 회수하도록 표시합니다. 메시지는 2~100자입니다. 나무 ID·내용·기간·상태가 저장됩니다.

샘플 나무는 `demo_pending`(체험 접수), 실제 데이터 연결 시 `pending_review`로 저장합니다. 자동 당첨·허가·실제 설치는 하지 않습니다. 운영자 심사와 관리 주체 허가, 수피·생육 영향 검토, 종료 후 회수 절차를 거쳐야 합니다. 부착이 적절하지 않으면 나무 곁 독립 안내대를 사용합니다. 고백은 상대방의 사전 동의 후 진행합니다.

## 연결 전인 운영 기능

- 실제 가로수 인벤토리: 현재 20그루 모두 샘플. 지도 도로는 실제이지만 나무의 존재·수종은 보증하지 않습니다.
- 카카오·구글 로그인: 별도 앱 등록, 콜백 URL, 인증키 필요. 현재는 HttpOnly 익명 쿠키로 식별하며 기기 간 로그인/복구를 제공하지 않습니다.
- 지도 주소 자동완성, 실제 지역별 집계·지도 클러스터·기기 방향 추적: 원본과 동일한 외부 데이터·지도 연동은 아직 아님. 현재 검색은 서울숲 주변 지명·좌표·GPS와 직접 지도 선택.
- 실물 이벤트 운영자 심사 화면, 실제 행사 승인·추첨·일정 운영과 제보 기관 전송은 연결되지 않았습니다.
- 공개 운영 전 개인정보 처리방침·보존 기간, 요청 제한·어뷰징 방지, 회원 관리, 실제 방문 검증을 확정해야 합니다. 원본 인증 코드를 그대로 신뢰하거나 원본의 15m/20m/10km 불일치를 복사하지 않았습니다.

원본 전체 기능이 외부 서비스까지 모두 연동된 상태로 주장하지 않습니다. `docs/feature-parity.md`에 구현과 차이를 명시했습니다.

## 검증

```sh
npm run typecheck
npm run lint
npm test
npm run build
```

API 스모크 테스트는 `TEST_ORIGIN`에 온라인 테스트 배포 주소를 지정한 뒤 `tests/*-smoke.mjs`를 실행합니다. 새 테스트용 익명 계정을 사용하며 클럽 테스트는 생성한 테스트 계정과 사진만 삭제합니다. 로컬 서버는 실행하지 않습니다. 브라우저 UI 검사는 별도 실행하지 않았습니다.

## 배포 상태

GitHub Actions 검증·배포 워크플로와 D1 마이그레이션/R2 바인딩을 준비했습니다. 최초 Cloudflare 계정·리소스·GitHub Secrets 연결이 필요합니다. 연결 및 실제 배포 성공 전에는 온라인 URL이 없습니다. Sites는 현재 워크스페이스에서 비활성화되어 사용하지 않습니다.
