# 시티트리클럽 주니어

서울환경연합과 함께하는 **팀 나무늘보** 제작. 김현진 · 김나현 · 박서연 · 정경섭 · 최미혜.

**사이트:** https://wukong-daima.github.io/citytreeclub-junior/

GitHub Pages에 배포하는 무료 개인 나무 관찰장입니다. 서버·Cloudflare·결제 수단·API 토큰 없이 이용합니다. main에 push하면 GitHub Actions가 검사와 정적 빌드 후 배포합니다. 로컬 서버는 필요하지 않습니다. [배포 안내](docs/github-deployment.md)

## 할 수 있는 일

- 지도·GPS·좌표와 300/500/1000/2000m 반경으로 가까운 10그루를 찾아 무작위 배정
- 최대 5그루 관리, 나무별 애칭·성장·경험치·장식, 관심나무
- 물주기·거름·방문 체험, 행동별 귀여운 효과와 5단계 튜토리얼
- 꼬물꼬물·가지·흙 돌봄 미니게임; 종류별 하루 25 XP
- 개인 관찰장: 수종·건강·둘레·크기·소감·사진, 수정·삭제
- 사진 재인코딩·최대1200px·EXIF 제거·자연/흑백/따뜻한 필터
- 100 누적 포인트부터 이름표·메시지·고백·장식 이벤트 신청 체험
- 낮/밤 테마, 동작 줄이기 지원, 기록과 사진 JSON 백업·복원

## 저장과 개인정보

모든 개인 데이터는 **현재 브라우저의 IndexedDB**에만 저장됩니다. 로그인·서버 저장·기기 간 동기화·사용자 간 댓글/사진 공유는 없습니다. GitHub에 개인 기록이 업로드되지 않습니다. 다른 브라우저나 기기에서 이어가려면 백업 파일을 내보내고 가져오세요. 브라우저 데이터 삭제·저장소 정리·비공개 모드 종료 등으로 기록이 사라질 수 있습니다. 백업에는 사진과 개인 기록이 포함되므로 안전하게 보관하세요.

사진은 한 장3MB·최대50장·총60MB, 가져오는 백업은100MB 이하입니다. 저장 실패는 화면에 표시합니다. 여러 탭의 변경은 IndexedDB 트랜잭션으로 순서대로 저장되지만 다른 탭 화면은 새로고침해야 최신 내용이 보일 수 있습니다. 브라우저 게임 특성상 경험치 조작 방지를 보장하지 않습니다.

## 실제 나무와 구분

지도 도로는 OpenStreetMap이며 외부 타일 서버에 접속합니다. **나무20그루는 모두 서울숲 주변 샘플 좌표**로 실제 나무의 존재·수종을 보증하지 않습니다. GPS는 검색 위치 선택용이며 실제 방문 인증은 제공하지 않습니다. 물·거름·가지 돌봄은 가상 게임입니다.

이벤트와 나무 제보는 **이 브라우저에만 저장되는 체험**이며 운영자·기관에 접수되지 않습니다. 실제 설치·승인·추첨·민원 전송은 하지 않습니다. 실물 이벤트를 운영하려면 관리주체 허가·비접촉 설치·기간 종료 후 회수 절차가 별도로 필요합니다. 나무에 못·접착제·철사를 사용하지 않습니다.

## 검사

Node.js24에서 서버 없이 실행합니다.

```sh
npm ci
npm run typecheck
npm run lint
npm test
npm run build
```

`dist/`만 정적 배포됩니다. `app/api`, `db`, `drizzle`, 기존 서버 테스트/타입은 이전 구현의 참고 자료이며 현재 앱이나 배포에서 실행되지 않습니다. Cloudflare 워크플로·배포 설정·비밀키는 제거했습니다. 원본 사이트 조사 자료는 `docs/reference-analysis.md`와 `docs/citytree-live-audit.md`에 남아 있습니다. `docs/feature-parity.md`는 서버 구현 시점의 역사적 대조표이며 현재 제공 범위는 이 README가 기준입니다.
