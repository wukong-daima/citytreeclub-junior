# citytree.club 공개 기능 조사

조사일: 2026-09-30. 대상: https://citytree.club/ . 공개 HTML과 연결된 공개 JavaScript를 읽었다. 로그인, 계정 생성, 원격 데이터 변경은 하지 않았다. 아래의 확인은 **화면과 클라이언트 구현 확인**이며 인증 후 서버 처리 성공을 검증했다는 뜻은 아니다. 원본 게시판 분석과 별도의 실제 서비스 조사다.

## 페이지와 기능

| 경로 | 공개 코드에서 확인한 기능 | 인증 및 한계 |
|---|---|---|
| `/` | 서울 범위 Mapbox 지도, 구·동별 나무 수, 줌 수준별 나무 마커, 건강 상태/내 나무/관심 나무 표시, 현재 위치, 확대·축소, 위치 중심/방향 추적 3단계, 위도·경도·줌 URL, 공지 배너 | 공개 지도. 데이터 API의 전체 실제 레코드는 수집하지 않음 |
| `/intro` | 잎사귀 순환 애니메이션, 첫 만남 시작, 둘러보기, 소개 | 공개 |
| `/sign-in` | 카카오/구글 OAuth 로그인·계정 만들기, 로그인 후 마이페이지 | `/auth/kakao`, `/auth/google`. 인증 실행 안 함 |
| `/assign` | 설정한 활동 동 선택, 랜덤 배정, 잎사귀 배정 애니메이션, 실제 위치 찾아가기 | 로그인 필요. `/api/trees/my/assign` |
| `/map?id=…` | 나무 위치 지도, 위치 추적, 만났다 버튼, 나중에 찾아가기, 오류 제보 | 로그인 필요. 거리 기준에 아래 불일치 있음 |
| `/register?id=…` | 다단계 최초 등록: 수종 → 애칭 → 건강 상태 → 둘레·덩치 → 소감·사진 → 완료·공유 | 로그인·배정자·클라이언트 진입 토큰 확인. 애칭 한글 완성형 최대 4자, 중복 검색. 둘레·덩치는 건너뛰기 가능 |
| `/detail?id=…` | 나무 이름·수종·동·둘레(cm)·덩치, 돌본 사람과 경과일, 건강 5부위, 마지막 수정자·날짜, 사진 슬라이더, 사진 업로드·본인 사진 삭제, 기록 타임라인, 텍스트·사진 댓글 생성/수정/삭제, 기록 좋아요·읽음 처리, 관심 나무 토글, 지도 보기, 링크·기록 단위 공유 | 상세 공개, 쓰기·좋아요·관심은 로그인 필요. 미배정/무명 나무와 자기 배정 나무는 관심 등록 제한. 업데이트·댓글은 내 나무 아닌 경우도 가능 |
| `/modify?id=…` | 애칭·수종·건강·둘레·덩치 수정, 가이드, 공유 | 로그인 필요. 애칭은 배정자만 수정하도록 UI 제한 |
| `/list-mine` | 내 나무 최대 5그루, 새 나무 배정, 미등록/등록 나무 구별, 배정일·경과일, 찾아가기, 상세, 오류 제보, 작별하기 | 로그인 필요. 작별 시 기록 유지·내 목록/애칭 제거·소식 중단 설명 |
| `/list-like` | 관심 나무 목록, 상세 보기, 오류 제보, 관심 해제 | 로그인 필요. 관심 해제 시 알림 중단 설명 |
| `/mypage` | 내/관심 나무 진입, 계정 관리, 읽지 않음/읽음 소식 타임라인, 기록 좋아요·읽음 처리, 동적 배너, Lottie 메뉴 애니메이션, 소개·제보 링크 | 로그인 필요 |
| `/account` | 이름, 활동 지역 주소 검색·최대 3개 선택, 최초 프로필 완성, 기존 프로필 수정, 로그아웃·계정 삭제 진입 | 로그인 필요. 지역 최소 1개 |
| `/account-delete` | 삭제 경고와 두 번 확인 | 공개 JS에 서버 수정 대기 메시지 존재. 실제 삭제 성공 기능으로 단정 불가 |
| `/reports.html` | 지도에 없는 나무 추가 제보 / 없어진 나무 제보, 지도 위치/기존 나무 선택, 설명·사진, 새 나무 수종·건강·둘레·덩치, 제출 완료 | `/api/reports/addition`, `/api/reports/removal`. 사진 필수. 실제 제출 안 함. auth-check 목록에는 단수 report만 있어 reports의 게이트 일치 여부 미검증 |
| `/info` | 소개, 이용약관, 개인정보 처리방침, FAQ, 후원, 공유, 협업 제안·의견 | 공개. 연결 문서 본문까지 완전 검증하지 않음 |

공통: 서울 일출·일몰 계산에 따른 주간/야간 색상 변경, Web Share와 클립보드 대체, 사진 리사이즈·필터(대략 800×1200·추가 압축, 3MB 제한), 수종/둘레/덩치 참고 가이드 이미지와 확대·축소.

## 건강 상태 원문과 분류

1. 태양: 햇빛이 잘 들지 않음
2. 수관: 가지치기가 과도하게 되어 있음
3. 줄기: 줄기에 큰 상처나 구멍, 썩은 부분이 있음
4. 줄기: 줄기에 줄이나 끈이 감겨있음
5. 뿌리: 뿌리가 잘리거나 썩어있음
6. 뿌리: 뿌리에 철사·고무줄이 감겨있음
7. 뿌리: 보도블럭이 솟아있음
8. 토양: 흙에 손가락이 들어가지 않을 만큼 딱딱함
9. 토양: 쓰레기나 담배꽁초 등이 있음
10. 해당사항없음 — 나머지 9개와 배타 선택

원본은 문제 항목 수 0~2 / 3~5 / 6개 이상으로 시각 상태를 구분한다. 이는 전문가 진단을 대체하는 기준이 아니므로 재구현 시 시민 관찰 상태로 표현해야 한다.

수종 선택: 은행나무, 회화나무, 양버즘나무, 메타세쿼이아, 느티나무, 이팝나무, 왕벚나무, 소나무, 기타 직접 입력. 덩치 선택: 앙상함 / 보통 / 아름드리.

## 구현 시 원본 그대로 복사하면 안 되는 사항

- 현장 접근 기준이 서로 다르다: 메인 마커는 20m, `/map`의 만났다 버튼은 15m, 별도 마커 클릭 분기는 10,000m. 클라이언트 sessionStorage 허가 토큰만으로 인증을 신뢰해서는 안 된다.
- 계정 삭제는 프런트 코드에 백엔드 수정 대기 표시가 있어 동작 완료로 간주할 수 없다.
- 공개 코드 접근 가능성은 그림/사진/코드 재사용 허가와 다르다. 원본 Mapbox 토큰, 추적 ID, 사용자 사진·개인정보를 가져오거나 재사용하지 않았다.
- OAuth, 실나무 데이터, 공동 기록의 실제 서버 운영, 운영자 제보 검토 결과는 인증 없이 검증하지 않았다. 체험용 익명 구현과 실제 로그인 연동을 구분해야 한다.
