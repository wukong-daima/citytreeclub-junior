# 실제 시티트리클럽 → 주니어 기능 대조

기준: 2026-09-30 https://citytree.club/ 공개 HTML·JS. 로그인 이후 원본 서버 작동 성공까지 검증한 것은 아님.

| 원본 기능 | 주니어 구현 | 차이·연동 조건 |
| --- | --- | --- |
| 소개·배정 애니메이션 | 소개, 5단계 실습 튜토리얼, 성공 축하 효과 | 자체 SVG/캐릭터 |
| 지도·현재 위치·확대 축소 | Leaflet/OSM, GPS, 지도 위치 선택, 반경 | Mapbox 대신 OSM. 나무는 샘플 |
| 구·동 집계, 클러스터, 건강/소유 레이어 | 가까운 후보 지도와 별도 내/관심 목록 | 실제 인벤토리·집계·레이어 연결 미완료 |
| 동별 랜덤 배정 | 지정 좌표 반경 안의 거리순 상위 10그루 중 무작위 | 사용자가 요청한 변경 사항 |

| 관심나무 | 등록·해제·목록·상세 | 샘플 무명 나무도 관심 등록 허용 |
| 현장 만남 인증 | GPS API 거리·정확도 검사, 샘플 방문 체험 분리 | 실제 데이터 없음. GPS 위변조 방지·실제 UI 운영은 후속 연결 |
| 최초 등록·정보 수정 | 수종/애칭/건강/둘레/덩치/사진/소감 5단계 | 미측정 허용, 원본보다 긴 16자 애칭. 관찰로 정보 갱신 |
| 건강 상태 | 원문 문제 9항목 + 배타적 해당없음 | 전문가 진단이 아닌 시민 관찰 |
| 사진 | R2 저장, 1200px 축소, JPEG 재인코딩, 필터, 권한·삭제 | 원본 가이드 사진은 복제하지 않음 |
| 공개 타임라인 | 공개/비공개 기록, 타인 나무 관찰, 최근 100개 | 페이지네이션 미구현 |
| 댓글·사진 댓글·수정·삭제 | 본인 권한 검사와 공개 기록 댓글 | 익명 체험 계정 |
| 좋아요·공유 | 좋아요 토글·수, 공개 기록 링크 복사 | 대외 공유는 실제 배포 URL 연결 필요 |
| 읽음·안읽음 소식 | 댓글/제보 알림과 읽음 처리 | 원본의 모든 외부 캠페인 배너·알림 발생기 미연동 |
| 계정·활동지역 | 활동 이름·3곳 저장·데이터 삭제 | 지역 자동완성/카카오/Google OAuth 미연결 |
| 추가/사라진 나무 제보 | 사진·좌표·수종·건강·치수 검증 및 저장 | 체험 심사 대기. 운영기관에 자동 전송 안 함 |
| 주간/야간 | 시스템 기본과 수동 낮/밤 정원 | 원본의 서울 일출·일몰 자동계산 대신 시스템 테마 |
| 안내·약관·개인정보·후원·협업 | 소개·팀원·데이터 안내·원본 출처 링크 | 실제 운영 약관, 후원 결제·협업 수신 채널 확정 필요 |

추가 주니어 기능: 물·거름·작명 애니메이션, 3종 돌봄 게임, 나무별 성장/누적 정성, 전체 포인트, 기간 제한 실물 이름표/메시지/고백/장식 응모.

운영 연동에 필요한 입력: 검증된 실제 나무 데이터 출처, 소셜 로그인 앱 등록과 서버 환경변수, 서비스 도메인, 행사 운영·승인 주체, Sites 활성화. 인증 비밀키는 채팅이나 소스에 넣지 않음.
