# 시티트리클럽 벤치마킹 분석

조사일: 2026-09-30. 원본 랜딩과 하단 게시판 1~5페이지의 공개 글 19개를 확인했다. 사용자가 제공한 `page=5`는 랜딩 하단 게시판의 마지막 페이지다. 실제 지도 서비스는 [citytree.club](https://citytree.club)로 연결된다.

## 분석 범위와 한계

- [공식 랜딩](https://www.seoulkfem.or.kr/citytreeclub/), 게시판 전체 목록 5페이지, 공개 게시글 19개, [제작 스튜디오 인터뷰](https://blog.sceneryoftoday.kr/citytreeclub/), [공식 출시 보도자료](https://seoulkfem.or.kr/newsroom/?bmode=view&idx=170345758)를 참고했다.
- 공개 HTML과 검색 결과로 기능·참여 구조를 분석했다. 로그인 이후 실제 배정·기록 흐름, 데이터베이스, 비공개 운영 화면은 검증하지 않았다.
- 게시글 본문은 모두 가져왔으나 일부 긴 인터뷰는 도구 출력 길이 제한으로 부분 확인했다. 이미지에만 담긴 행사 세부사항과 각 이미지 파일의 시각 내용은 개별 검증하지 않았다. 따라서 원본 전체 기능에 대한 실사용 감사로 보아서는 안 된다.
- FAQ는 클라이언트 렌더링으로 제목만 확인됐다. 미확인 동작을 원본의 확정 기능으로 가정하지 않았다.

## 원본의 핵심 경험

지도에서 생활권의 나무를 배정받고, 애칭을 지어주고, 건강 상태와 사진을 기록한다. 다른 참여자의 나무를 관심나무로 등록하고 댓글로 소식을 나눈다. 베타 모집 안내에는 최대 5그루 배정과 기록 10회·설문 참여 보상이 명시되어 있다.

건강 상태는 시민이 눈으로 관찰할 수 있는 항목을 중심으로 한다. 공식 출시 자료는 과도한 가지치기, 줄기의 상처·구멍·썩은 부분, 단단하게 굳은 흙 등을 포함하는 9개 항목을 소개한다. 기록은 나무의 과거 상태와 변화에 대한 근거를 만들며, 시민의 관심을 가시화하는 역할을 한다.

원본 레터에는 가까운 나무를 받기 위해 재배정했다는 경험이 있다. 도시나무모임의 지정 좌표·반경·거리순 최대 10그루 중 무작위 배정은 생활 동선과 나무의 관계를 강화하는 개선이다. 후보가 10개 미만이면 그 후보만 사용하고, 0개이면 반경 변경을 안내해야 한다.

## 도시나무모임에 적용할 방향

1. 선택 위치의 반경 안에서 거리를 계산하고 가까운 최대 10그루만 서버에서 추첨한다. 사용자에게 후보 수·거리·샘플 여부를 명확히 보여준다.
2. 방문과 관찰 기록이 가상 정원의 성장으로 연결된다. 같은 날 반복 클릭으로 무한 성장하지 않도록 날짜별 보상을 제한한다.
3. 물·거름·장식은 가상 정원 행동으로 명시한다. 실제 가로수에 임의로 물이나 비료를 주도록 게임이 유도하지 않는다.
4. 현장 이벤트는 운영 주체·조건·기간·회수 책임이 정해진 프로그램으로 설계한다. 이름표는 나무 몸체 대신 승인된 독립 안내대에 두는 방향을 제안한다. 체험 방문과 실제 방문은 조건 집계에서 분리한다.
5. 사계절 관찰 배지, 같은 자리 비교 사진, 나무 그늘 지도, 함께 살펴보는 이웃 미션, 관찰 기록 내보내기를 후속 기능으로 제안한다. 방문하지 못한 날의 벌점이나 나무 죽음 연출보다 오랜 관심을 보상한다.

## 구현 범위 해석

현재 프로토타입의 서울숲 나무는 실측 목록이 아닌 샘플이다. 실제 나무 데이터·지도·회원 인증·사진 기록·현장 인증과 승인 운영을 연결하기 전에는 실서비스로 볼 수 없다. 이벤트 관심 등록 역시 참가 확정이나 실제 설치 허가가 아니다. 원본의 민원 비율·환경 효과 등 수치를 새로운 서비스의 자체 검증 성과로 표시해서는 안 된다.
