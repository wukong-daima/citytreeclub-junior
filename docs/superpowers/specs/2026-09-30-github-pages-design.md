# GitHub Pages 무료 전용 전환 설계

## 승인된 목적과 제약

사용자는 Cloudflare와 결제 수단 없이 GitHub만으로 접속 가능한 웹사이트를 원한다. 로컬 서버는 실행하지 않는다. 공개 저장소 전환과 아래 기능 범위 변경은 대화에서 승인했다. 이 문서는 구현 전 상세 범위 검토용이다.

## 유지할 사용자 경험

기존 React 화면, 팀 소개, 나무 그림, 애니메이션, 튜토리얼을 재사용한다. 지도 위치 선택·반경 검색·가장 가까운 10그루 중 무작위 배정, 최대 5그루 관리, 작명, 물·거름, 나무별 경험치·성장·장식, 세 가지 미니게임, 개인 관찰 기록을 유지한다. 현재 나무 20개는 계속 샘플로 표시한다. 지도 타일은 기존 OpenStreetMap 외부 요청이며 별도 과금형 지도 API는 추가하지 않는다.

## 구조와 데이터

Vite React 정적 앱을 GitHub Pages의 `/citytreeclub-junior/` 경로에 배포한다. 런타임 서버 API 호출을 브라우저 저장 서비스 호출로 바꾼다. 기존 서버 API와 D1/R2 코드는 정적 빌드에서 제외하고 Cloudflare 배포 설정 및 의존성은 제거한다. Git 기록으로 이전 구현을 보존한다.

브라우저 IndexedDB에 내 나무·개인 기록·사진·설정·게임 진행과 체험 신청을 저장한다. 저장 서비스는 UI와 분리하고 기존 거리·성장 검증 함수를 재사용한다. 사진은 기존 크기 제한과 재인코딩을 유지하며 IndexedDB Blob으로 저장한다. 저장 용량 오류·저장 차단은 성공으로 숨기지 않고 안내한다. 다른 기기·브라우저와 자동 동기화하지 않는다. 브라우저 데이터 삭제 시 기록이 사라짐을 처음부터 안내한다.

개인용 게임이므로 일일 제한과 보상 검증은 브라우저에서 수행한다. 서버 검증·부정행위 방지·실제 위치 방문 인증이 보장된다는 표현을 제거한다. GPS는 근처 검색용이며 방문은 체험 기록이다.

## 공유 기능과 이벤트

공개 커뮤니티·타 사용자 댓글·공동 사진 공유·계정 로그인·제보 기관 전송은 제공하지 않는다. 기존 기록 화면은 개인 관찰장으로 바꾼다. 공유 버튼은 사이트 주소만 공유하며 개인 데이터 공개 링크를 생성하지 않는다.

100 포인트 이벤트와 메시지는 '이 기기에만 저장되는 체험 신청'으로 유지한다. 실제 운영자에게 접수되거나 추첨·승인이 진행되는 것으로 표시하지 않는다. 실제 나무에 못·접착제·철사 등을 사용하지 않는 보호 원칙과 관리주체 허가·기간 종료 후 회수 원칙을 유지한다.

## 백업과 복원

버전이 있는 JSON 백업에 개인 기록과 사진을 포함한다. 내보내기는 파일 다운로드, 가져오기는 파일 선택과 사용자 덮어쓰기 확인으로 제공한다. 가져오기는 파일 크기·스키마·배열 길이·필드 범위·사진 형식을 검증하고 전체 검증에 성공한 경우만 트랜잭션으로 교체한다. 잘못된 파일은 현재 기록을 변경하지 않는다. 백업 파일에 개인정보가 포함될 수 있음을 알린다.

## 배포와 비용 경계

저장소를 공개로 전환하고 GitHub Pages 공식 Actions 방식으로 배포한다. main 변경 시 검사·빌드·배포하며 정적 파일 외 서버는 운영하지 않는다. Cloudflare Actions를 중지하고 API 토큰/계정 ID secrets를 제거한다. Cloudflare 계정 탈퇴·결제 설정 변경은 하지 않는다. 무료 GitHub Pages 이용 한도 내에서 운영하며 무제한 트래픽을 약속하지 않는다.

## 검증 및 완료 기준

단위 테스트로 후보 거리·추첨·나무별 성장·일일 행동 제한·게임 보상·체험 신청·백업 왕복·잘못된 백업의 원본 보존을 검증한다. 타입·린트·정적 빌드를 실행한다. 로컬 서버는 실행하지 않는다. GitHub Actions의 실제 배포 성공과 온라인 HTML/JS/CSS 응답, 저장 서비스의 API 의존성 제거를 확인한다. 별도 요청 없는 브라우저 UI 조작 검사는 하지 않는다. 실제 발급·접속 검증한 Pages 주소를 전달한다.

## 대안 검토

Cloudflare 무료 한도 방식은 계정·결제 연결 부담 때문에 제외한다. GitHub Pages에서 공유 DB를 흉내 내기 위해 저장소에 사용자 토큰을 넣거나 공개 이슈를 개인 기록 저장소로 쓰지 않는다. 순수 정적 앱과 브라우저 저장이 승인된 무료·개인 체험 범위에 맞는 선택이다.
