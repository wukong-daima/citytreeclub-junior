# 구현 원칙

- 튜토리얼 버그(2026-09-30): 가이드 CTA는 현재 탭으로 다시 이동하는 것으로 끝내지 않는다. 첫 단계는 배정 창, 물주기는 실제 돌봄 등 눈에 보이는 결과를 연결하고 단계별 버튼을 직접 검증한다.
- 반경 안내(2026-09-30): 감성적인 질문에 위치 기준, 선택 범위, 결과에 미치는 영향과 직선거리 여부를 인접 설명으로 명시한다.

- 결과 전달 보완(2026-09-30): 승인받은 변경을 설계 문서만 올리고 완료한 것처럼 전달하지 않는다. 사이트 주소 요청에는 배포 여부를 먼저 밝히고, 승인된 범위의 구현·배포·실제 기능 검증까지 이어간다.

- 비용 제약 보완(2026-09-30): 무료 체험 요구에 결제 수단 등록이 필요한 외부 서비스를 먼저 요구하지 않는다. GitHub Pages의 정적 호스팅 한계와 브라우저 저장의 손실·동기화 제약을 설명하고 승인된 범위만 구현한다.

- 배포 요청(2026-09-30): 로컬 서버 실행을 결과물로 제시하지 않는다. 사용자가 로컬 서버를 금지하면 기존 서버도 종료하고, GitHub 기반 배포와 실제 온라인 URL을 검증한다. 호스팅 인증이 없으면 기능을 정적 데모로 축소하지 말고 필요한 연결을 명확히 요청한다.

- 사용자 보완(2026-09-30): 실제 나무 장식을 배제하는 안내만으로 끝내지 않는다. 가상 장식과 포인트 응모·운영자 검토·관리주체 허가·기간 제한을 거치는 실물 이벤트를 각각 구현한다.
- 돌봄 서비스의 성과는 숫자 저장뿐 아니라 행동 애니메이션, 단계별 목표, 투입한 노력, 첫 실행 안내로 눈에 보이게 한다.
- 사용자 제공 제작팀·협업 표기를 반영하고, 기존의 '제휴 없음' 설명과 충돌하지 않게 모든 노출 지점을 확인한다.
